## [Job Hunt Pipeline](https://github.com/carlosedbaptista/job-hunt-pipeline)

An unattended pipeline that finds engineering roles in Zurich, scores them
against my profile with an LLM, and writes a tailored CV and cover letter for
the ones worth applying to. Twice a day on GitHub Actions since June 2026.

The interesting part is not that it works. It is what happened when I audited
it after three months.

**917 of 917 job descriptions were exactly 500 characters, every one cut
mid-sentence** — the job board's API truncates them. What survives is the
marketing pitch; what is lost is the requirements list, which is where the
disqualifiers live. One posting scored **82/100 → APPLY** on its teaser and
**58 → SKIP** on the full text, which demanded five years of full-stack
development and a B.Sc. Every score above the APPLY threshold in the entire
history had been given on truncated text.

The model was never wrong. It was handed 12% of the posting.

The fix reads the employer's own applicant tracking system instead
(Greenhouse, Lever, Ashby and four more): **40% hit rate, measured**. The
other 60% keep the teaser and are explicitly flagged as low-confidence, so
they can never reach APPLY. Half-knowledge that announces itself is
trustworthy; confident half-knowledge is what produced the 82.
