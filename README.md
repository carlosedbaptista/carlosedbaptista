## 📂 Featured Project

### 🤖 Job Hunt Pipeline · AI-Powered Job Automation

An automated job search and evaluation pipeline for Data and Business Analyst positions in Switzerland. It collects job postings from multiple sources, scores fit with AI, generates a daily ranked digest, and produces tailored application materials — all running twice daily via GitHub Actions.

**What it does in production:**

| Feature | Detail |
|:---|:---|
| 🔍 **Multi-source ingestion** | Adzuna API + Gmail IMAP for portal job alerts |
| 🧠 **AI evaluation** | 0-100 fit scoring with APPLY / REVIEW / SKIP decision |
| 📊 **Interactive dashboard** | HTML with Chart.js, dark mode, filters, 30-day history — <a href="https://carlosedbaptista.github.io/job-hunt-pipeline/digests/dashboard.html" target="_blank" rel="noopener noreferrer"><b>see live ↗</b></a> |
| 📄 **Document generation** | Tailored CV and cover letter for jobs scoring 85+ |
| ☁️ **Google Drive integration** | Automatic upload of materials per company and job |
| 📧 **Notifications** | Formatted HTML email with the daily digest |
| 💾 **Tracking** | SQLite database with application history and follow-ups |
