## Featured Project

### Job Hunt Pipeline · AI-Powered Job Automation

[![Repo](https://img.shields.io/badge/Repository-job--hunt--pipeline-1e3a5f?style=flat-square&logo=github&logoColor=white)](https://github.com/carlosedbaptista/job-hunt-pipeline)
[![Live Dashboard](https://img.shields.io/badge/Live-Dashboard-1dd1a1?style=flat-square&logo=googlechrome&logoColor=white)](https://carlosedbaptista.github.io/job-hunt-pipeline/digests/dashboard.html)
[![Status](https://img.shields.io/badge/Status-Active%20in%20Production-success?style=flat-square)](https://github.com/carlosedbaptista/job-hunt-pipeline)

An automated job search and evaluation pipeline for Data and Business Analyst positions in Switzerland. It collects job postings from multiple sources, scores fit with AI, generates a daily ranked digest, and produces tailored application materials, running twice daily via GitHub Actions.

**What it does in production:**

- **Multi-source ingestion:** Adzuna API plus Gmail IMAP for portal job alerts
- **AI evaluation:** 0 to 100 fit scoring with an APPLY / REVIEW / SKIP decision
- **Interactive dashboard:** HTML with Chart.js, dark mode, filters, and 30-day history
- **Document generation:** tailored CV and cover letter for jobs scoring 85 or higher
- **Google Drive integration:** automatic upload of materials per company and job
- **Notifications:** formatted HTML email with the daily digest
- **Tracking:** SQLite database with application history and follow-ups
