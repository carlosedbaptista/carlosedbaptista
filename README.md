### 🤖 Job Hunt Pipeline — <i>AI-Powered Job Automation</i>

> Automated job search and evaluation pipeline for Data/Business Analyst positions in Switzerland. Collects jobs from multiple sources, evaluates fit with AI (Kimi/Moonshot AI), generates a daily ranked digest, and creates personalized application materials — all running 2x daily via GitHub Actions.

**Features in production:**
- 🔍 <b>Multi-source ingestion:</b> Adzuna API + Gmail IMAP (portal job alerts)
- 🧠 <b>AI evaluation:</b> 0-100 scoring with APPLY/REVIEW/SKIP decision
- 📊 <b>Interactive dashboard:</b> HTML with Chart.js, dark mode, filters, and 30-day history — <a href="https://carlosedbaptista.github.io/job-hunt-pipeline/digests/dashboard.html" target="_blank" rel="noopener noreferrer">see live ↗</a>
- 📄 <b>Document generation:</b> Tailored CV + Cover Letter for jobs with score ≥85
- ☁️ <b>Google Drive integration:</b> Automatic upload of materials per company+job
- 📧 <b>Notifications:</b> Formatted HTML email with daily digest
- 💾 <b>Tracking:</b> SQLite with application history and follow-ups
