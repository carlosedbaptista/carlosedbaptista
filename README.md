### 🤖 Job Hunt Pipeline — *AI-Powered Job Automation*

> Automated job search and evaluation pipeline for Data/Business Analyst positions in Switzerland. Collects jobs from multiple sources, evaluates fit with AI (Kimi/Moonshot AI), generates a daily ranked digest, and creates personalized application materials — all running 2x daily via GitHub Actions.

**Features in production:**
- 🔍 **Multi-source ingestion:** Adzuna API + Gmail IMAP (portal job alerts)
- 🧠 **AI evaluation:** 0-100 scoring with APPLY/REVIEW/SKIP decision
- 📊 **Interactive dashboard:** HTML with Chart.js, dark mode, filters, and 30-day history — [see live](https://carlosedbaptista.github.io/job-hunt-pipeline/digests/dashboard.html)
- 📄 **Document generation:** Tailored CV + Cover Letter for jobs with score ≥85
- ☁️ **Google Drive integration:** Automatic upload of materials per company+job
- 📧 **Notifications:** Formatted HTML email with daily digest
- 💾 **Tracking:** SQLite with application history and follow-ups
